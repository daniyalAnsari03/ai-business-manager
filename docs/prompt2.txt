* Google
* Email

Use the appropriate public Supabase configuration only where permitted.

Keep authentication server-aware and secure.

# STEP 7 — BUSINESS OWNERSHIP

This is extremely important.

Every business must belong to the authenticated user/account.

Do NOT trust a client-provided `business_id` as sufficient authorization.

The server must derive ownership from the authenticated session.

Establish the foundation required for future modules such as:

* products
* customers
* orders
* inventory
* sales
* expenses
* employees
* documents
* AI business context

to remain isolated by business.

---

# STEP 8 — ROW LEVEL SECURITY

Implement Supabase RLS for the business profile data created in this phase.

Users must only be able to access their own business data.

Test policies logically for:

* SELECT
* INSERT
* UPDATE

Do not create an insecure policy such as:

"authenticated users can access all businesses."

Never rely only on frontend filtering.

Only collect information that is genuinely useful for the application.
