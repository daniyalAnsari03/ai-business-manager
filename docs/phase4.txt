# 2. Phase 4 Goals

Phase 4 has four major capabilities:

### A. Approval + Automation Control

Add a business-level automation control with two modes:

* **Needs approval**
* **Full auto**

### B. WhatsApp Approval

When approval is required, the AI can send an approval request through WhatsApp.

The user can reply:

* `haan`
* `yes`
* `approve`

to approve.

Or:

* `nahi`
* `no`
* `reject`

to reject.

The system must securely map the response to the correct pending action.

### C. In-App Review

Users must be able to review pending actions inside the application.

They can:

* Review
* Approve
* Reject

the pending AI action.

### D. Weekly WhatsApp Report + Video AI

Every week the system should be able to send the business owner a marketing summary through WhatsApp.

Also add a Video feature where the user uploads a video and AI prepares:

* Caption
* Hashtags
* Suggested posting time

The system must not automatically publish the video unless the existing automation/approval rules explicitly allow it.

# 6. Approval Action System

Do not build approvals as a simple boolean.

Create a proper pending-action model.

A pending AI action should contain enough information to identify:

* Business
* User
* Action type
* Action payload
* Human-readable summary
* Current status
* Approval mode
* Created time
* Expiration time if applicable
* Approved/rejected time
* Approved/rejected by
* Execution time
* Execution result
* Error state
* External reference if applicable
* Idempotency key

Possible statuses:

```text
pending
approved
rejected
executing
completed
failed
expired
cancelled
```

Use database constraints/enums where appropriate.

# 7. Approval Lifecycle

The correct lifecycle should be:

```text
AI decides an action is needed
        ↓
Action is validated
        ↓
Automation mode checked
        ↓
Needs approval?
     /        \
   YES         NO
    ↓           ↓
Create       Execute
pending      eligible
action       action
    ↓
Notify user
    ↓
User reviews
    ↓
Approve / Reject
    ↓
Approved?
  /      \
YES       NO
 ↓         ↓
Execute   Reject
 ↓
Verify result
 ↓
Completed
```

Never execute a `pending` action.

Never execute a rejected action.

Never execute an expired action.

# 10. WhatsApp Reply Processing

Incoming WhatsApp messages must be securely handled.

The system must:

1. Verify webhook authenticity/signature according to the selected WhatsApp provider.
2. Identify the authenticated/connected business.
3. Identify the sender.
4. Confirm the sender is authorized to approve actions.
5. Identify the correct pending action.
6. Reject ambiguous approval replies.
7. Prevent unauthorized users from approving.
8. Prevent replay attacks where applicable.
9. Prevent duplicate approval execution.
10. Make approval processing idempotent.

Do NOT simply search for the latest pending action and approve it.

The approval request must have a secure identifier/reference.
